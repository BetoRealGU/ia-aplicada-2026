# Política de datos del proyecto

## 1. Alcance

Esta política aplica al proyecto de mejora de áreas verdes en Aguascalientes. Se utilizan datos sobre la ubicación de parques, estado de conservación, mantenimiento, cantidad de áreas verdes y vegetación. El objetivo es utilizar la información únicamente para el desarrollo y análisis del proyecto.

## 2. Ciclo de vida

Los datos pasan por las etapas de captura, almacenamiento, uso, compartición, retención y eliminación. En cada etapa se aplican controles para mantener la información protegida y utilizarla únicamente para los fines del proyecto.

## 3. Normativa aplicable

El proyecto toma como referencia la LFPDPPP de México, la Ley de IA de la Unión Europea y el NIST AI RMF. Estos marcos permiten identificar buenas prácticas relacionadas con la protección de datos, el uso responsable de inteligencia artificial y la gestión de riesgos.

## 4. Controles comprometidos

Se utilizarán únicamente los datos necesarios para el proyecto. El acceso a la información estará controlado, se registrarán las fuentes y se mantendrá supervisión humana. También se revisarán posibles riesgos y sesgos, se establecerá un periodo de retención y se realizará un borrado seguro cuando los datos ya no sean necesarios.

## 5. Manejo de datos con herramientas de IA

Se podrán utilizar herramientas como ChatGPT, Gemini, DeepSeek o Dify únicamente con información que no sea personal, sensible o confidencial. No se ingresarán datos personales ni información privada sin autorización. Antes de utilizar una herramienta de IA se revisará qué información se comparte y se utilizará únicamente lo necesario para realizar la actividad.

## 6. Revisión

Esta política será revisada cuando cambien los datos, las herramientas utilizadas o las necesidades del proyecto. Si se detectan nuevos riesgos, se actualizarán los controles necesarios para mantener un manejo responsable de la información.
